# チャット内の劇団検索

基準main: 1a75382。ブランチ: codex/chat-search-20261122。

左側に劇団名・大学名の検索欄を追加。全劇団を部分一致で検索し、自分を除外。英字の大小と前後空白を無視。空欄は従来の履歴あり会話一覧。検索中は履歴ありを最新順、その後に未会話の相手を表示。未読バッジを維持。検索結果はキーボードで選べるボタン。Escapeで検索解除。ログイン切替時に検索語を消去。

既存selectChatPartnerを再利用し、開くだけでは会話履歴に追加せず最初の保存成功後に追加。通知・認証・ディープリンク・依頼辞退処理は変更なし。DB変更不要。

検証: node --test tests/search.test.cjs tests/messages.test.cjs で38件成功。git diff --check成功。
